# Roadmap

This roadmap is a working list, not a promise of release dates.

## Current priorities

- Keep installation, backup, restore, and upgrade paths dependable.
- Improve accessibility and usability across desktop and mobile.
- Publish versioned releases with clear upgrade notes.

## Propose or discuss work

Open a GitHub issue with the problem and a concrete example. Do not attach real expense data, receipts, credentials, or backups. See [CONTRIBUTING.md](../CONTRIBUTING.md).
